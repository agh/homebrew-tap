# Homebrew Tap

Personal Homebrew tap for [@agh](https://github.com/agh).

## Usage

```bash
brew tap agh/tap
brew install agh/tap/cwtch
```

## Formulae

| Formula | Description |
|---------|-------------|
| `cwtch` | Manage Claude Code profiles and synchronise configuration from Git ([agh/cwtch](https://github.com/agh/cwtch)) |

## Casks

| Cask | Description |
|------|-------------|
| `input` | Work Louder's configurator for its keyboards and macro pads; updates itself ([worklouder.cc/input](https://worklouder.cc/input)) |
