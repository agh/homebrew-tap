# Homebrew Tap

Personal Homebrew tap for [@agh](https://github.com/agh).

## Usage

```bash
brew tap agh/tap
brew install agh/tap/cwtch
```

## Formulae

| Formula | Description |
|---------|-------------|
| `cwtch` | Manage Claude Code profiles and synchronise configuration from Git ([agh/cwtch](https://github.com/agh/cwtch)) |

## Casks

| Cask | Description |
|------|-------------|
| `input` | Work Louder's configurator for its keyboards and macro pads; updates itself ([worklouder.cc/input](https://worklouder.cc/input)) |
| `insta360-wave-controller` | Insta360's controller for its Wave microphones; updates itself ([insta360.com](https://www.insta360.com/product/insta360-wave)) |
| `lg-switch` | LG's monitor controls and screen layouts. LG's installer also adds fonts, helpers in `/usr/local/switch`, a launch agent and a login item, which the cask's uninstall removes ([lg.com](https://www.lg.com/us/support/monitors)) |
